Desenvolvedor apaixonado por arquitetura limpa, código bem estruturado e soluções inovadoras. Com formação em Sistemas de Informação, atuo criando desde aplicações web e mobile até a integração de inteligência artificial.

* 🏢 Atualmente atuo como **Full Stack Developer / Tech Lead**, liderando projetos e integrações entre frontend e backend.
* ⚙️ Foco principal de desenvolvimento em **Node.js, React, React Native, TypeScript e Python**.
* 🤖 Experiência na construção e otimização de **Agentes de IA (RAG)** utilizando ferramentas como a API do Gemini, ChromaDB e modelos HuggingFace.
